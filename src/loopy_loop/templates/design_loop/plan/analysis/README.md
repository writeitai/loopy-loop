# Analysis

Evidence and argument — **why we believe things**. May be messy; superseded analyses are
preserved as the audit trail. Never binding on its own.

- `problem_frame.md` — the job, users, domain invariants, vocabulary (cold-readable).
- `research/<investigation-id>/` — durable investigation trees (brief, `sources.md`
  acquisition manifest, evidence memos, `proposal_fit/`, `verify/`, `saturation.md`,
  `04_synthesis.md`). Only these trees make gitignored `_additional_context/` citable.
- `objections.md` — numbered step-back critique (O-entries) with dispositions.
- `design_reviews/` — dated whole-corpus coherence reviews (F-entries).
- `phase_reviews/` — digest-pinned sufficiency reports for the director.

Evidence statuses and the no-laundering flow: `plan/README.md`.
