# Architecture Decision Log

The canonical, indexed history of every material design commitment. Conventions:
stable D-numbers (`## D1. <title>`), each entry carries **Decision / Context /
Consequences**, cites the analysis and proposals (absorbed AND rejected) behind it, and
links the binding design. Refinements append a "Refined by Dn" note to the older entry;
withdrawn entries remain as tombstones; numbers are never reused. See `plan/README.md`.

Written only by `design_bind` sessions.
